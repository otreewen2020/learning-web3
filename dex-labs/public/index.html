🎰 链上赌场（blockhash 延迟开奖 + 固定赔率）

原理：本区块的哈希在本块内永远读不到（EVM 只存最近 256 个区块哈希）。下注时承诺"3 个区块后的哈希"做种子，之后任何人 reveal 开奖：结果 = hash % 100。出块者下注时也无法预知未来哈希——但注意 blockhash 仍可被重仓庄家轻微操纵，真实产品必须用 Chainlink VRF。
尚未部署。赔率：开小(<50) 1.98× / 开大(≥50) 1.96× / 押中数字(1%) 90×。

🛡️ 身份与权限（AccessControl + 白名单 mint）

原理：权限不是"一个 owner"，而是角色 → 成员的多对多关系。 角色是 bytes32 标识（= keccak256("MINTER_ROLE")）。合约内置三个角色： DEFAULT_ADMIN（发/收角色）、MINTER（铸币）、PAUSER（暂停）。 本页会造两个"员工"钱包演示：授权 → mint 成功 → 回收 → mint 被拒 → 暂停 → 恢复。
尚未部署。部署者只拿 DEFAULT_ADMIN_ROLE——不是万能 owner，发角色之外寸步难行。

🌉 跨链桥（锁仓 + 映射发行，同链双合约模拟两侧）

原理：桥不创造资产——A 侧（源链）把真币锁进金库， 验证者对 (单号, 收款人, 金额) 签名，B 侧（目标链）收齐多数签名后 放行等量映射币；回程反之：烧掉映射币，A 侧验签后放还真币。 本页在同一条 Besu 链部署 A/B 两个金库合约 + 一个映射代币来模拟。
尚未部署。需要先备好预言机数据源（📡 预言机页 → 准备数据源），验证者即它们。
